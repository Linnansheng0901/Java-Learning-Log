##### 哈希冲突

不同对象的哈希值/哈希定位结果出现相同，导致他们进入同一个位置；这时候必须用`equals()`进一步判断它们是否真的相等

             add(Student)
                  ↓
              hashCode()
                  ↓
          ┌───────┴───────┐
          ↓               ↓
      不同位置          相同位置
          ↓               ↓
       直接放入         发生哈希冲突
                          ↓
                       equals()
                          ↓
                  ┌───────┴───────┐
                  ↓               ↓
                true             false
                  ↓               ↓
                重复             都保留
                 不加

```text
1. equals() 相等
   → hashCode() 必须相同

2. hashCode() 相同
   → 不一定 equals() 相等
```

#####Comparable

这个类自己规定，默认怎么比较

```java
class Student implements Comparable<Student>{
    int id;
    public Student(int id){
        this.id = id;
    }
    @Override
    public int compareTo(Student o){
        return this.id - o.id;
    }
}
```

1.implements:Student类实现了Comparable接口

2.`Comparable<Student>`:表示Student可以和另一个Student进行比较

3.必须重写comparaTo：TreeSet需要排序，告诉java排序规则

4.comparable():负数：当前对象排在前面；0：TreeSet认为重复；正数：当前对象排在后面 

5.在**`set.add(...)`**处开始调用CompareTo()

##### Comparator

在类外额外提供一种比较规则

1.`Comparator<Student> idComparator = new Comparator<Student>() {}`

创建比较器，比较Student的规则，

2.`TreeSet<Student> set = new TreeSet<>(idComparator);`

将规则交给TreeSet

|                  | Comparable    | Comparator        |
| ---------------- | ------------- | ----------------- |
| 写在哪里         | 类里面        | 类外面            |
| 方法             | `compareTo()` | `compare()`       |
| 作用             | 默认排序规则  | 临时/额外排序规则 |
| 是否修改 Student | 要            | 不需要            |
| TreeSet          | 可以使用      | 可以使用          |

```java
import java.util.Comparator;
import java.util.TreeSet;

class Student implements Comparable<String>{
    private int id;
    private String name;
    private double score;
    
    public Student(int id,String name,double score){
        this.id = id;
        this.name = name;
        this.score = score;
    }
    
    public int getId(){
        return id;
    }
    public String getName(){
        return name;
    }
    public double getScore(){
        return score;
    }
    
    //Comparable:id
    @Override
    public int comparaTo(Student other){
        return Integer.compare(this.id,other.id);
    }
    @Override
    public String toString(){
        return "Student{" + 
            "id=" + id +
            ", name='" + name + '\'' +
            ",score=" + score +
            '}';
    }
}
public class Test{
    public static void main(String[] args){
        Student s1 = new Student(1003, "张三", 85);
        Student s2 = new Student(1001, "李四", 92);
        Student s3 = new Student(1005, "王五", 78);
        Student s4 = new Student(1002, "赵六", 92);
        Student s5 = new Student(1004, "小明", 85);
        
        // 第一种：使用 Comparable
        
        TreeSet<Student> studentById = new TreeSet<>();
        
        studentsById.add(s1);
        studentsById.add(s2);
        studentsById.add(s3);
        studentsById.add(s4);
        studentsById.add(s5);
        
        System.out.println("按学号排序>>>");
        for(Student student : studentById){
			System.out.println(student);
        }
        
        // 第二种：使用 Comparator
        
        Comparator<Student> scoreComparator = new Comparator<Student>(){
            @Override
            public int compare(Student s1,Student s2){
                // 第一比较条件：成绩降序
                if(s1.getScore() != s2.getScore()){
                    return Double.compare(s2.getScore(),s1.getScore());
                }
                return Integer.compare(s1.getId(),s2.getId());      
            }
        };
        
        TreeSet<Student> studentByScore = new TreeSet<>(scoreComparator);
        
        studentsByScore.add(s1);
        studentsByScore.add(s2);
        studentsByScore.add(s3);
        studentsByScore.add(s4);
        studentsByScore.add(s5);
        System.out.println("\n按照成绩排序：");

        for (Student student : studentsByScore) {
            System.out.println(student);
        }
        
    }
}
```

#### HashMap

```text

       ↓
    Key → Value
       ↓
Key 唯一，Value 可以重复

Key 的判断涉及 hashCode + equals
```
