####try-catch:处理异常

**try 中一旦发生异常，异常发生位置后面的代码不会继续执行。**

```java
try {-使用资源
    // 可能发生异常的代码
} catch (异常类型 变量e) {-处理异常
    // 异常发生后执行这里
}finally{-释放资源
    //无论是否发生异常，通常都会执行
}
```

```text
Student s
   ↓
s 是 Student 对象的引用变量

Exception e
   ↓
e 是 Exception 对象的引用变量，异常对象

getMessage()---获取异常的描述信息
printStackTrace()---打印异常的详细调用栈
```

####字节流

**字节输入+字节输出:文件复制**

```java
import java.io.FileInputStream;
import java.io.FileOutputSream;
import java.io.IOException;

public class Test{
    public static void main(String[] args) throws IOException{
        FileInputStream fis = new FileInputStream("D:\\Java\\a.jpg");
        FileOutputStream fos = new FileOutputStream("D:\\Java\\b.jpg");
        //一次读取一个字节
        int data;
        while((data = fis.read()) != -1){
            fos.write(data);
        }
        //准备一个byte数组
        byte[] buffer = new byte[1024];
        int len;
        //
        while((len = fis.read(buffer)) != -1){
            fos.write(buffer,0,len);
        }
        //关闭流->否则可能造成资源泄漏
        fis.close();
        fos.close();
        
        System.out.println("复制成功");
    }
}
```

1.`while((len = fis.read(buffer)) != -1)`--->分两步：`fis.read(buffer)`->读取一批字节放进buffer；第一步读完以后会返回这一次实际读取的字节个数，存入len中。

2.`fos.write(buffer,0,len);`--->写入的对象，从哪里开始，读取长度。避免把本次读取没有覆盖的旧数据也处理进去

**try-catch-finally**

```java
import java.io.FileInputStream;
import java.io.IOException;

public class Test {
    public static void main(String[] args) {

        FileInputStream fis = null;

        try {
            fis = new FileInputStream("D:\\Java\\test.txt");

            int data;

            while ((data = fis.read()) != -1) {
                System.out.println((char) data);
            }

        } catch (IOException e) {
            System.out.println("读取文件出错");
        } finally {

            if (fis != null) {
                try {
                    fis.close();
                } catch (IOException e) {
                    System.out.println("关闭文件出错");
                }
            }
        }
    }
}
```

**try-with-resources**

```java
        try(FileInputStream fis = new FileInputStream("D:\\Java\\test.txt")){
            int data;

    }
}
```

|           | `try-catch-finally` | `try-with-resources`          |
| --------- | ------------------- | ----------------------------- |
| 异常处理  | `catch`             | `catch`                       |
| 资源关闭  | 自己写 `close()`    | Java 自动关闭，在try(...)里面 |
| 主要使用  | 通用异常处理        | 管理需要关闭的资源            |
| 代码长度  | 较长                | 简洁                          |
| IO 中推荐 | 可以                | **更推荐**                    |

#### 字符流

```java
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;

public class CharacterStreamDemo{
    public static void main(String[] args){
        String sourcePath = "D:\\Java\\a.txt";
        String targetPath = "D:\\Java\\b.txt";
        
        // 读取 a.txt，写入 b.txt
        try(
            FileReader fr = new FileReader(sourcePath);
            FileWriter fw = new FileWriter(targetPath);
        ){
            char[] buffer = new char[1024];
            int len;
            while((len = fr.read(buffer)) != -1){
                fw.write(buffer,0,len);
            }
            System.out.println("文件复制完成");
        }catch(IOException e){
            System.out.println("文件操作失败");
            e.printStackTrace();
        }
        
        // 追加内容
        try(FileWriter fw = new FileWriter(targetPath,true)){
            fw.write("\n");
            fw.write("这是追加到文件末尾的内容");
            
            System.out.println("追加内容完成");
        }catch(IOException e){
            e.printStackTrace();
        }
    }
}
```
