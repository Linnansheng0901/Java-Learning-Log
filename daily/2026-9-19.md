### 11.3线程生命周期与安全

```text
                 new Thread()
                     ↓
                   NEW---新建
                     ↓
                  start()
                     ↓
                RUNNABLE---可运行
               ↙    ↓    ↘
          sleep()   执行   等待锁
             ↓              ↓
限时等待--TIMED_WAITING    BLOCKED---阻塞
             ↓
          时间到
             ↓
         RUNNABLE

RUNNABLE
   ↓
wait()/join()
   ↓
WAITING---无限等待
   ↓
条件满足
   ↓
RUNNABLE

RUNNABLE
   ↓
run()执行完
   ↓
TERMINATED---终止
```

```text
线程安全:多个线程同时操作同一个共享数据，导致最终结果和预期不一致

共享数据--->多个线程同时访问同一份数据
竞态数据--->多个线程同时操作共享数据，最终结果会因为线程执行顺序不同而产生差异

原子性--->一个操作执行过程中能不能被其他线程干扰
可见性--->一个线程修改共享变量后其他线程可不可以看到
有序性--->操作的先后顺序符合预期
```

### 11.5Lock

**ReentrantLock/synchronizede---可重入，一个线程已经拿到一把锁,有资格再次拿这把锁。如果多个方法使用的是同一把锁，那么已经持有这把锁的线程，可以进入这些方法；其他线程必须等待**

```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

class Counter{
    private int count = 0;
    private Lock lock = new ReentrantLock();
    public void add(){
        
        if(lock.tryLock()){
            try{
                count++;
                
                System.out.println(
                	Thread.currentThread().getName() + ":执行成功，count = " + count
                );
            }finally{
                lock.unlock();
            }
        }else{
            System.out.println(
                Thread.currentThread().getName() + ":没有获取到锁"
            	);
        }
        public int getCount(){
            return count;
        }
    }
}

public class Main{
    public static void main(String[] args) throws InterruptedException{
        Counter c = new Counter();
        Thread t1 = new Thread(() ->{
            for(int i=0;i < 5;i++){
                c.add();
            }
        },"线程1");
        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 5; i++) {
                c.add();
            }
        },"线程2");
        
        
        t1.start();
        t2.start();
        
        t1.join();
        t2.join();
        
        System.out.println("最终结果:" + c.getCount());
    }
}
```

### 11.6线程通信

**wait()：进入等待状态；释放当前持有的锁**

**notify():唤醒一个正在等待的线程**

**notifyAll():唤醒所有等待的线程，重新竞争同一把锁**

```java
class Box{
    private int value;
    //仓库没有数据
    private boolean hasValue = false;
    
    public synchronized void put(int value) throws InterruptedException{
        //仓库一次放一个数据
        while(hasValue){
            wait();
        }
        this.value = value;
        hasValue = true;
        
        System.out.println("生产：:" + value);
        
        notifyAll();
    }
    
    public synchronized int get() throws InterruptedException{
        while(!hasValue){
            wait();
        }
        
        int result = value;
        hasValue = false;
        
        System.out.println("消费:" + result);
        
        notifyAll();
        return result; 
    } 
}


public class Main{
    public static void main(String[] args){
        //共享数据--存有value,hasValue
        //存放在堆内存里
		Box box = new Box();
        
        Thread producer = new Thread(() -> {
            for(int i=1;i <= 5;i++){
                try{
                    box.put(i);
                }catch(InterruptedException e){
                    e.printStackTrace();
                }
            }
        },"生产者");
        
        Thread consumer = new Thread(() -> {
            for(int i=1;i <= 5;i++){
                box.get();
            }catch(InterruptedException e){
                e.printStackTrace();
            }
        },"消费者");
        
        producer.start();
        consumer.start();
    }
}
```

**饥饿：长期等不到资源/执行能力**

**竞态条件：多个线程同时操作共享数据，最终结果取决于线程执行的先后顺序**

**数据不一致：竞态条件可能造成的结果不相同**

#### 2.CountDownLatch

让一个线程等待其他线程完成，相当于倒计时

```java
public class Main{
    public static void main(String[] args) throws InterruptedException{
        
        CountDownLatch latch = new CountDownLacth(3);
        
        Thread t1 = new Thead(() -> {
			System.out.println("任务1完成");

        	latch.countDown();	
        });
        Thread t2 = new Thread(() -> {
            System.out.println("任务2完成");

        });

            System.out.println("任务3完成");

        });
```

#### 3.CyclicBarrier

让多个线程互相等待，等大家到齐后，再一起继续

```java
import java.util.concurrent.CyclicBarrier;

public class Main(String[] args){
    CyclicBarrier barrier = new CyclicBarrier(3);
    
    Runnable task = () -> {
        try{
            System.out.println(
                Thread.currentThread().getNamae() + "到达集合点"
            );
            barrier.await();
            System.out.println(
                Thread.currentThread().getName() + " 开始执行下一阶段"
            );            						
        }catch(Exception e){
            e.printStackTrace();
        };
        
        new Thread(task, "线程1").start();
        new Thread(task, "线程2").start();
        new Thread(task, "线程3").start();
    }
}
```

|              | CountDownLatch            | CyclicBarrier    |
| ------------ | ------------------------- | ---------------- |
| 核心思想     | **等任务完成**            | **等线程到齐**   |
| 谁等待       | 通常一个线程等待          | 多个线程互相等待 |
| 核心方法     | `countDown()` + `await()` | `await()`        |
| 能否重复使用 | ❌ 通常一次                | ✅ 可以循环       |
| 类比         | 倒计时                    | 集合点           |

#### 4.Semaphore

```java

public class Main {
    public static void main(String[] args) {

        for (int i = 1; i <= 6; i++) {
            int id = i;
            new Thread(() -> {

                    //获取许可
                    semaphore.acquire();                
                    System.out.println(

                    );
				    //归还许可

                } catch (InterruptedException e) {
                    e.printStackTrace();
                }

            }).start();
        }
    }
}
```
