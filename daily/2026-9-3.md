###6.9多态

```java
class Animal{
    public void eat(){
        System.out.println("动物吃东西");
    }
}

class Dog extends Animal{
    @Override
    public void eat(){
        System.out.println("狗吃骨头");
    }
}
```

```java
Animal a1 = new Dog();
引用类型         实际对象
a1.eat();

//狗吃骨头
```

####6.9.1成员访问特点

**a1是Animal类型的引用变量，所以通过a1只可以使用Animal中定义的成员(变量和方法)**

**对象实际是谁，看new；引用能操作什么，看左边的类型**

**成员变量 -> 看引用类型** 

**静态方法 -> 看引用类型/类**

**实例方法 -> 看实际对象**

**构造方法不参与多态**

```java
public class Test {
    public static void main(String[] args) {
        ⭐feed(new Dog());
        feed(new Cat());
    }

    // Animal 是父类类型的参数
    ⭐public static void feed(Animal animal) {
        animal.eat();
    }
}

// 父类
class Animal {
    public void eat() {
        System.out.println("动物吃东西");
    }
}

// 子类
class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗吃骨头");
    }
}

// 子类
class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("猫吃鱼");
    }
}
```

```text
① new Dog()
      ↓
   创建Dog对象
      ↓
② 直接把这个对象的引用
作为参数交给feed()参数为Animal类型的引用变量
      ↓
③ animal接收到这个引用
```

####6.9.2向上转型、向下转型

向上转型:子类 --> 父类(自动)

`Animal a1 = new Dog();`

向下转型:父类 --> 子类(为了使用Dog自己的方法)

```java
if (a instanceof Dog){
    Dog d = (Dog) a;
    d.play();
}
```

意思是如果a实际上是Dog，再把它转换成Dog(安全检查)
