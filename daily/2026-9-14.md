### 6.10接口interface

**主要是统一调用**

```java
interface 接口名{
    方法;
}
```

```java
//Run是一个接口，规定任何实现Run接口的类，都必须提供run()方法的实现
interface Run{
    void run();
}
interface Swim{
    void swim();
}
class Dog implements Run,Swim{
    @Override
    public void run(){
        System.out.println("狗在跑");
    }
    @Override
    public void swim(){
        System.out.println("狗在游泳");
    }
}

public class test1 {
    public static void main(String[] args){
        //1.类似多态，但创建了两个对象
        Run a = new Dog();
        Swim b = new Dog();
        a.run();
        b.swim();
        //2.一个对象接多个接口
        Dog dog = new Dog();
        //**run的引用类型变量是Run且指向dog这个对象
        所以只可以使用对应的方法--run.swin();❌
        Run run = dog;
        Swim swim = dog;
        
        run.run();
        swim.swim();
    }
}
```

|             | `extends` | `implements` |
| ----------- | --------- | ------------ |
| 类 → 类     | ✅         | ❌            |
| 类 → 接口   | ❌         | ✅            |
| 接口 → 接口 | ✅         | ❌            |
| 一个类多个  | ❌多个父类 | ✅多个接口    |

**`void run();===public abstract void run();`**

abstract--->这个方法没有具体的实现

因为接口要求方法是public，不可以降低权限，Dog在重写run()时必须是公开的public.

**特性:public static final---公开、可以直接访问、不可以改变**

### 6.11抽象类abstract

```java
//这个类是抽象的，代表一个不完整的、抽象的概念，本身不能直接创建对象
abstract class Animal {
    public void eat() {
        System.out.println("吃东西");
    }
    public abstract void sound();
}
```

**实现接口的类必须实现接口方法**

**抽象类：是什么 + 共同代码eat() + 强制要求sound() **

####abstract VS interface

|                | 抽象类    | 接口                   |
| -------------- | --------- | ---------------------- |
| 主要表达       | 是什么    | 能做什么               |
| 继承方式       | `extends` | `implements`           |
| 一个类能有几个 | 一个父类  | 多个接口               |
| 能有普通方法   | ✅         | 可以有，但核心作用不同 |
| 能有抽象方法   | ✅         | ✅                      |
| 能直接 `new`   | ❌         | ❌                      |

```text
类继承：
一个类只能 extends 一个父类
→ 避免多个父类的实现产生继承冲突

接口：
一个类可以 implements 多个接口
→ 可以组合多个“能力”
→ 如果多个接口发生默认方法冲突，就由类自己解决
```

### 6.12内部类

```text
内部类
├── *成员内部类
├── *静态内部类
├── 局部内部类
└── *匿名内部类
```

####成员内部类



```java
class Outer{
    class Inner{
        public void test(){
			System.out.println("Inner");
        }
    }
}
//创建inner对象
Outer.Inner inner = new Outer().new Inner();
inner.test();
```

**1.`Outer.Inner`--->Outer中定义inner类**

**2.`outer.new Inner()`--->先创建一个Outer对象，再通过这个Outer对象创建它对应的成员内部类Inner对象**

**3.Inner()可以访问Outer里的成员**

**4.普通成员内部类属于某一个 Outer 对象，因此创建 Inner 对象时，需要先有一个 Outer 对象**

#### 静态内部类

```java
class Outer{
    static class Inner{
        
    }
}

//创建inner对象
Outer.Inner inner = new Outer.Inner();
```

**1.Inner()只可以访问static成员**

**2.静态内部类不依赖某一个具体的 Outer 对象，而是属于 Outer 这个类，所以可以直接通过 `Outer.Inner` 创建**

#### 匿名内部类

**条件：一个父类or接口；临时实现/继承它；无需类名**

**没有类名的接口实现/继承父类 + 创建对象**

**没有类名，但有引用变量**

```java
接口类型  引用变量
Dog      dog = new Dog() {
    @Override
    public void eat() {
        System.out.println("狗吃东西");
    }
};

dog.eat();

创建一个“匿名类”的对象
        ↓
这个匿名类实现了 Dog 接口
        ↓
把这个对象的引用交给变量 dog
```

**没有类名与引用变量**

```java
new Dog() {
    @Override
    public void eat() {
        System.out.println("狗吃东西");
    }
}.eat();

new Swim(){...}
      ↓
创建匿名实现类对象
      ↓
对象直接调用 .swim()
      ↓
输出“游泳”
```

#####缓冲流

```text

 ↓
FileInputStream
 ↓
```

```java
**字节流的缓冲
import java.io.*;
public class Test{
    public static void main(String[] args){
        try(BufferedInputSream bis = 
            new BufferedInputStream(new FileInputStream("D:\\Java\\z.jpg"));
           BufferedOutputSream bos = 
            new BufferedOutputStream(new FileOutputStream("D:\\Java\\b.jpg"))
           ){
            byte[] buffer = new byte[1024];
            int len;
            while((len = bis.read(buffer)) != -1){
                bos.write(buffer,0,len);
            }
            System.out.println("复制成功");
        }catch(IOException e){
            e.printStackTrace();
        }
    }
}
```
