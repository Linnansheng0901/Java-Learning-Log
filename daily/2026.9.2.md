##⭐7.继承(extends)

```java
class 子类 extends 父类{
    
}
```

子类 = 父类已有的东西 + 子类自己新增的东西

一个类只能继承一个父类，子类不可以继承父类的private

### 7.1方法重写@Override(不可以修改权限)

**判断：方法名相同+参数列表相同**

**final修饰方法---不可以修改权限**

```java
class Animal{
    public void eat(){
        System.out.println("动物吃东西");
    }
}
```

```java
class Dog extends Animal{
    @Override
    public void eat(){
        System.out.println("狗吃骨头");
    }
}
```

###7.2super

**调用当前对象的父类部分的成员变量和方法**

super()必须放在第一行

一个构造方法不可以同时使用this()和super()：他俩都需要放在第一行，并且一个构造方法只可以先选择一个方向

#### ⭐7.2.1调用父类构造方法

父类：

```java
class Person {

    String name;

    public Person(String name) {
        this.name = name;
    }
}
```

子类：

```java
class Student extends Person{
    int age;
    public Student(String name,int age){
        super(name);
        this.age = age;
    }
}
```

**父类与子类都含参构造方法时，子类通过`super()`调用父类构造方法，把参数传给父类，让父类完成自己的成员变量初始化**

**创建子类对象时：先父类构造，再子类构造**

**若父类只有有参构造，子类为无参构造：子类在构造方法中必须通过`super(参数)`调用父类的有参构造方法，并传入参数**
